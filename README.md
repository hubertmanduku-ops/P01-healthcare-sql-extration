# P01 Healthcare SQL Extraction

## Healthcare Data Extraction and Analytics Preparation Project

### Overview

This project demonstrates the use of SQL and Python to extract, transform, and prepare healthcare operational data from a PostgreSQL database for downstream analytics and reporting.

The project simulates a real-world business scenario where a hospital requires consolidated patient, appointment, and billing information to support financial analysis, operational reporting, and future machine learning initiatives.

The solution connects to a PostgreSQL database hosted on Supabase, executes SQL extraction queries against the healthcare schema, and generates a clean CSV dataset that serves as the source for subsequent ETL and analytics workflows.

---

## Business Scenario

### Client

**St. Aurelius General Hospital**

### Consulting Company

**MedCore Analytics**

### Role

**Data Analyst**

St. Aurelius General Hospital manages large volumes of operational data across multiple systems. Patient demographics, appointment records, physician assignments, departmental information, and billing transactions are stored in separate relational tables.

The Finance and Analytics teams require a consolidated dataset to:

* Analyze patient service utilization
* Monitor appointment activity
* Evaluate billing performance
* Support revenue reporting
* Enable future business intelligence and machine learning initiatives

To address this requirement, this project extracts and combines data from multiple healthcare tables into a single flat-file dataset.

The primary objectives of this project are:

## Data Extraction Workflow

1. Connect to the PostgreSQL healthcare database.
2. Execute SQL extraction queries.
3. Join patient, appointment, billing, doctor, and department data.
4. Load query results into Python.
5. Export the dataset to CSV format.
6. Store the final output in the data directory.
